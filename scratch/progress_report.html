1. Executive Summary & Cross-Platform Architecture

BrishtiLibrary (বৃষ্টি লাইব্রেরি) has been upgraded with pure C99 cross-platform abstraction layers to support native compilation on both Linux (POSIX sockets, POSIX clock, dirent) and Windows (Winsock2, QPC).

The backend server remains 100% C code with zero external runtime requirements. SQLite is bundled directly via the official amalgamation (sqlite3.c). A multi-stage Dockerfile and a Linux Makefile have been added to allow zero-configuration deployment to free cloud platforms (such as Render, Fly.io, Railway, or Koyeb).

5. Next Step: Free Public Deployment

To deploy the application online for free:

  1. Push the repository to GitHub.
  2. Log in to Render.com (or Fly.io / Railway).
  3. Create a New Web Service connected to your GitHub repo.
  4. Render automatically detects the root Dockerfile, compiles the C backend in Alpine Linux, sets the PORT variable, and provisions a free HTTPS public URL (e.g. https://brishtilibrary.onrender.com).
